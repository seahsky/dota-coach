    5API keysAPI keys and custom command

    Anthropic API key

    Reviews call Claude through the Anthropic API and are billed to this key (console.anthropic.com). It is saved to the skill's .env.

    On Cloudflare the key is a Worker secret. Set or change it from the skill folder with npx wrangler secret put ANTHROPIC_API_KEY

    STRATZ token

    A STRATZ token adds ranked per-position stats and bracket matchups. Get one at stratz.com/api. It is saved to the skill's .env.

    On Cloudflare: npx wrangler secret put STRATZ_API_KEY

    After-match command

    Runs instead of the Claude review, e.g. to post to Discord. It gets DOTACOACH_MATCH_ID, DOTACOACH_ACCOUNT_ID, DOTACOACH_HERO and DOTACOACH_REVIEW_FILE as environment variables. Leave empty to use Claude.

    Use the in-game map picture

    The coach doesn't ship Dota's map art, so save a copy of the minimap yourself: a top-down picture of the whole map, Radiant bottom-left (Liquipedia's "Gamemap simplemap" or "minimap" file for the current patch works). It stays in the skill folder as map.png, .jpg or .webp and is never uploaded or committed.

    Edges: which map cell each side of the picture sits on. If the green and red ward marks sit off the lanes, nudge these until the "where heroes walked" layer lies on the lanes, then save.
