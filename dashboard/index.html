    1Your accounts

    Your Friend ID is on your Dota profile (top left). A Steam64 id or an OpenDota, Dotabuff, STRATZ or Steam /profiles/ link also works.

    Coaching notes

    Main role, hero pool, goals. The coach reads these before every answer and review.

    2Connect Dota 2

    Dota's Game State Integration tells the coach the moment a game ends. Do this on the PC you play on.

    2. In Steam: right-click Dota 2 > Properties > General > Launch Options, add -gamestateintegration
    3. Restart Dota, start the watcher below, and open any game (a bot match works). The light turns green when Dota checks in.
    Signal from Dota: never

    Valve has said GSI can cost some frame rate. Remove the launch option to turn it off.

    5Optional: STRATZ and custom command

    A STRATZ token adds ranked per-position stats and bracket matchups. Get one at stratz.com/api. It is saved to the skill's .env.

    After-match command

    Runs instead of the Claude review, e.g. to post to Discord. It gets DOTACOACH_MATCH_ID, DOTACOACH_ACCOUNT_ID, DOTACOACH_HERO and DOTACOACH_REVIEW_FILE as environment variables. Leave empty to use Claude.
